IropkeBatang-subset.woff2 in this directory is a MODIFIED subset of IropkeBatangM.woff
(glyphs for the home page definition line "개념, 구성, 판단, 추리 따위를 행하는 인간의 이성 작용" and Basic Latin).
Because the Reserved Font Name must not be used by modified versions, the internal font names were changed
to "Definition Serif" (the file name only says where it came from). The CSS family alias is "Definition Serif".

Regenerate (after changing the text; needs fonttools + brotli; rename name IDs 1,3,4,6 afterwards with fontTools):
  pyftsubset IropkeBatangM.woff --text="<text>" --unicodes="U+0020-007E" --flavor=woff2 \
    --layout-features='*' --no-hinting --name-IDs='*' --output-file=IropkeBatang-subset.woff2
