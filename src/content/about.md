# About

**TheMan의 Patch Notes**: 기술을 읽고, 생각을 적는다.

## 이 블로그가 다루는 것

기술·AI·보안의 기술과 동향, 그리고 그것을 바라보는 블로그 운영자(TheMan)의 사유를 기록합니다. 부제는 IT Security Blog입니다.

## 이렇게 읽어 주세요

글은 세 섹션으로 나뉩니다.

- **Tech**: 손으로 직접 확인한 기술 기록. 분석 과정과 코드를 함께 적습니다.
- **Trends**: IT·AI·보안 분야의 동향과 트렌드, 새로운 기술을 소개합니다.
- **Essays**: 보안을 하며 떠오른 생각을 천천히 적은 글입니다.
